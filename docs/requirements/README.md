# Requirements — Persona Voice Chatbot

Working name: **Persona Voice**. A chatbot that replies with the personality of a specific person
(learned from their chat history) and speaks in their cloned voice, with expressive delivery
(laughs, sighs, soft tone…) driven by that person's own emotional and emoji habits.
